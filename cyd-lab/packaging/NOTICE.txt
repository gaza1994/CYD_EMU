Espressif ESP32 mask ROM (esp-rom-elfs)
  NOT included in this zip. On first run cyd-lab downloads Espressif's
  esp-rom-elfs release 20260528 from github.com/espressif/esp-rom-elfs
  (Apache License 2.0) and checks its SHA-256 before use.

Arduino platform files written by "Set up Arduino IDE"
  platform.txt is generated from the user's installed "esp32 by Espressif
  Systems" Arduino core (LGPL-2.1 / Apache-2.0, see that package); cyd-lab
  copies the recipes it needs and adds its own discovery and monitor lines.

ESP-IDF second-stage bootloader and Arduino-ESP32 default partition table
  Embedded in cyd-lab.exe, used only by "Install anyway" for an app-only image
  on a blank board. bootloader.bin is the ESP32 bootloader built from ESP-IDF
  v5.5.5 as shipped in the Arduino-ESP32 3.3.12 core (esp32-arduino-libs):
  Copyright Espressif Systems (Shanghai) Co Ltd, Apache License 2.0
  (https://github.com/espressif/esp-idf). The partition table is the core's
  default.csv layout (https://github.com/espressif/arduino-esp32, tools/
  partitions/default.csv; Arduino-ESP32 is LGPL-2.1-or-later). The table
  is a list of partition offsets and sizes, compiled with gen_esp32part.
  Both are included unmodified.

Firmware catalogue (built into cyd-lab.exe)
  The list of firmware (names, descriptions, download URLs and SHA-256 hashes)
  is cyd-lab's own, MIT. No firmware binaries are included; the gallery
  downloads them from each project's own release on demand. Each project
  keeps its own licence, which the gallery shows (MIT, GPL-3.0, AGPL-3.0,
  EUPL-1.2, ...). The thumbnails are pictures of each firmware's screen as
  drawn in the emulator, shown only to identify the firmware; the artwork
  belongs to the respective projects (openHASP, NerdMiner, Bruce, ESP32
  Marauder, CYD-Klipper, the ESP32-Cheap-Yellow-Display examples, the CYD
  Weather Dashboard and the ESP32 CYD Weather Station). The ESPHome starter config is cyd-lab's
  own (MIT). The Tasmota display.ini and template notes follow the
  community template at templates.blakadder.com (sunton_ESP32-2432S028).

ESPHome for Home Assistant (with screen): the one firmware image built in
  cyd-lab.exe ("bundled" in the gallery). Built by cyd-lab with ESPHome
  2026.10.0 from esphome-ha\cyd-2432s028r.yaml (included in this folder;
  cyd-lab's own config, MIT). The image contains ESPHome's C++ runtime
  (GPL-3.0, https://github.com/esphome/esphome, tag 2026.10.0), ESP-IDF
  (Apache-2.0, Espressif), LVGL (MIT) and the components the config lists.
  Rebuild it from that config with "esphome compile" and ESPHome 2026.10.0.
